# ClipNotes

把微信、小红书、抖音的收藏链接丢给 MoviePilot，自动抓取正文 → 用系统已配置的 LLM 整理 → 生成 Obsidian 风格 Markdown，并通过 REST API 交付给未来的 Obsidian 插件（本插件**不直接读写 Obsidian Vault**）。

- 插件 ID：`ClipNotes`
- 当前版本：`1.0.9`
- 接口契约：[SYNC_PROTOCOL.md](./SYNC_PROTOCOL.md)（增量同步协议 v1，客户端按这份文档实现即可）

## 1. 用途与边界

**做**：

- 收录链接 → 抓取正文（含标题层级、列表、引用、代码块、图片）→ 结构化整理 → 持久化 → 提供同步 API
- 同一链接自动去重（规范化 URL + 哈希），重复提交不会产生新笔记
- 图片落盘到本地，Markdown 里的引用可由同步端替换成本地文件
- 任务失败可重试，AI 整理可重试

**不做**：

- 不写 Obsidian Vault、不移动你的 Obsidian 文件（由未来的 Obsidian 插件负责）
- 不导出 `.md` 文件到目录（Markdown 只通过 API 提供）
- 不依赖任何第三方解析服务（仅作为可选兜底，留了配置位）
- 不使用 Playwright（小红书只做直接 HTTP 解析）

## 2. 快速开始

1. 安装并启用插件（插件市场 → 本地插件源里的 **ClipNotes**）
2. 保持默认配置即可用；建议确认这两项：
   - `允许的顶层分类`：AI 只会在这个列表里选分类，默认 `Inbox / NAS / 开发 / 软件 / 生活 / 知识 / 说明书 / 项目 / Obsidian / Archive`
   - `微信菜单归属分类`：默认 `订阅`，决定企业微信菜单里 ClipNotes 挂在哪个一级菜单下
3. 在机器人里发一条：

```
/note https://mp.weixin.qq.com/s/xxxxxxxx
```

4. 收到「已收录，稍后自动抓取并整理」，随后会收到「ClipNotes 整理完成」

## 3. 命令

`/笔记` 与 `/note` **完全等效**（`/note` 是为了兼容只接受拉丁字符命令名的渠道，例如 Telegram）。

| 命令 | 说明 |
|---|---|
| `/note <链接>` | 收录链接，立即返回任务 id |
| `/note list` | 查看最近 10 条记录及状态 |
| `/note retry <id>` | 重新处理指定记录（支持 id 前缀匹配） |
| `/note` 或 `/note help` | 查看使用说明，并开启 20 秒链接输入窗口 |

### 20 秒链接输入窗口

只发送命令、不带参数时，除了回使用说明，还会开启一个 **20 秒**的输入窗口——窗口内直接发链接即可，不必再打命令。

| 窗口内发送内容 | 处理 |
|---|---|
| 链接 | 直接收录 |
| `/note`、`/笔记` | 命令优先，重开一个全新的 20 秒窗口 |
| 其它命令（如 `/sites`） | 命令优先，正常执行 |
| `list` / `retry <id>` | 按子命令执行 |
| 普通文字（含 `help`、`?`） | 不收录，回使用说明并重开窗口 |
| `取消` / `退出` / `q` / `quit` / `exit` | 立即关闭窗口 |
| 什么都不发 | 20 秒后静默失效，不会有多余提示 |

窗口机制说明：

- 窗口依赖 MoviePilot 的「插件输入会话」，它在消息链路中**先于全局智能体被消费**，所以窗口内的裸链接不会被智能体截走
- 窗口计时是精确的（会话创建时间 + 20 秒），**从最近一次触发开始算**：窗口内再次触发（发命令或普通文字）会重新计时
- 窗口结束后插件会主动清理会话，避免 MoviePilot 推送多余的「插件输入已超时」提示
- 窗口失效后发来的裸链接会按 MoviePilot 的全局规则交给 **AI 智能体**（因为本机开启了 `AI_AGENT_GLOBAL`），智能体通常会替你调用 `/note`，但行为和耗时不可预期

## 4. 各渠道入口

### 企业微信应用（自定义菜单）

插件会把命令注册进企业微信的自定义菜单：

```
订阅  →  管理订阅 / ClipNotes        ← 点击「ClipNotes」等于发送 /笔记
```

- 企业微信限制：一级菜单最多 3 个、每个一级最多 5 个子项。MoviePilot 只取前 3 个分类，所以插件默认**不单独占用一级菜单**，而是并入「订阅」（可用 `微信菜单归属分类` 改到别的分类，留空则回到"独立一级菜单"）
- 菜单项名统一显示为 `ClipNotes`
- 同一分类下名称相同的命令会自动去重（`/笔记` 与 `/note` 只保留一个按钮）
- 点击菜单项 → 发送 `/笔记`（无参数）→ 直接进入 20 秒窗口 → 你只需要发链接

> 卸载插件后菜单项**不会立即消失**（MoviePilot 的卸载流程没有触发菜单重注册）。想临时去掉菜单项，请用「禁用插件」；禁用会立即刷新菜单。

### Telegram

- 命令菜单里会出现 `/note`（Telegram 的 `BotCommand` 只接受 `a-z0-9_` 形式，因此 `/笔记` 按渠道规范被剔除，不出现在菜单里，但手动输入 `/笔记` 依然可用）
- 插件重载时会强制刷新各渠道菜单，无需重启 MoviePilot

### 网页 / 其它

通过 API 提交（见 [第 9 节](#9-对外-api)），适合快捷指令、书签、自建脚本。

## 5. 支持的平台

| 平台 | 解析方式 | 备注 |
|---|---|---|
| 微信公众号 | `httpx` + BeautifulSoup，正文取 `#js_content` | 代码块按行还原；空列表项与隐藏节点自动清理 |
| 小红书 | 短链先解析跳转 → 解析页面 `window.__INITIAL_STATE__` | 失败时回退 og 信息；可再回退到可选的第三方服务 |
| 抖音 | 短链先解析跳转 → 用爬虫 UA（Baiduspider / Googlebot）抓取 SEO 版本页面 → 解析 meta 描述 | 提取文案、话题标签、作者、发布时间、点赞数与封面图；无播放地址（接口有签名校验） |
| 其它站点 | 兜底解析：标题 / 描述 / 主图 | 保证任何链接都能落库 |

- 平台识别按域名自动完成；识别不到的按「其它」处理
- 可用开关单独关闭微信、小红书或抖音解析，关闭后对应链接改走兜底解析（不会失败）
- 小红书支持 `xhslink.com` / `xhslink.cn` 短链与完整笔记链接，两种形式命中去重后的同一条记录
- 抖音支持 `v.douyin.com` 短链与 `www.douyin.com/video/<id>` 完整链接，两种形式命中去重后的同一条记录
- 抖音分享页是客户端渲染的，普通 UA 只能拿到空壳；插件改用搜索引擎爬虫 UA 请求同一地址，触发服务端渲染的 SEO 版本拿到文案
- 正文图片会被下载到本地（每篇最多 20 张），失败的图片保留原始地址并记录原因

## 6. AI 整理规则

使用 MoviePilot 已配置的 LLM（默认跟随系统设置，可在插件里覆盖提供商/模型），只做结构化，不参与抓取。

输出结构固定为：

```json
{
  "title": "整理后的标题（去标题党，≤40 字）",
  "summary": "1~3 句摘要（≤150 字）",
  "category": "必须是配置的分类白名单中的一个",
  "tags": ["2~8 个中文关键词"],
  "language": "zh-CN"
}
```

- **分类越界会强制回退为 `Inbox`**，不会出现白名单外的分类
- 标题用于 Markdown 的 H1、建议文件名与列表展示；**原始标题保留在 frontmatter 的「原始标题」字段**
- 送进模型的正文会被截断（`AI 输入正文上限`，默认 4000 字符），并附带标题与正文小标题，避免长文超限
- AI 调用失败会按 `AI 整理最大重试次数`（默认 3）重试；达到上限后**降级为无 AI 结果**继续生成 Markdown，不会卡住任务

## 7. 生成的 Markdown

以 Obsidian frontmatter + 正文的形式生成：

```markdown
---
标题: 常用Linux命令汇总与速查
原始标题: "能用到“退休”的 600条 Linux 命令，可以解决日常99%的问题~"
来源: 微信
URL: https://mp.weixin.qq.com/s/9hsVOE-u1bQ_tcbxO4h55Q
作者: Linux运维进阶之路
发布时间: 2024-12-06 08:08:00
分类: 知识
状态: 待读
标签:
  - Linux
  - 命令行
  - 运维
摘要: 文章整理了约600条常用Linux命令……
content_id: 24e81f5e89e08f72
抓取时间: 2026-10-07 01:35:02
整理时间: 2026-10-07 01:40:13
---

# 常用Linux命令汇总与速查

> 文章整理了约600条常用Linux命令……

（正文，保留标题层级 / 列表 / 引用 / 代码块 / 图片）
```

字段说明：

| 字段 | 说明 |
|---|---|
| 标题 | AI 整理后的标题，也是建议文件名（`GET /notes/{id}` 的 `filename` 字段） |
| 原始标题 | 抓取到的原题，永远不会丢失 |
| 分类 | AI 在白名单内选择的分类，仅作为 Property，**不会**据此移动文件 |
| 状态 | 由配置 `Markdown 初始状态` 决定，默认 `待读` |
| 标签 / 摘要 | AI 生成 |
| content_id | 去重标识，同一条笔记在 API 与 ack 中都用它 |
| 抓取时间 / 整理时间 | 用于排查与同步比对 |

> 正文中的图片仍是原始 CDN 地址（会过期）。同步端应下载 `assets[].api_path` 对应的本地文件并替换引用——详见 [SYNC_PROTOCOL.md](./SYNC_PROTOCOL.md)。

## 8. 数据存放位置

| 内容 | 位置 |
|---|---|
| 笔记正文、AI 结果、Markdown、索引 | MoviePilot 数据库（插件数据表，一条笔记一个 key） |
| 图片资源 | `/config/plugins/ClipNotes/assets/`（文件名 = 内容哈希） |
| 配置 | MoviePilot 系统配置（插件配置项） |

图片去重：小红书 CDN 的地址每次请求都会变化，因此按路径末段的内容标识计算哈希，重复处理同一篇笔记不会重复占盘。

## 9. 对外 API

基址（`v1` 与 `v2` 前缀等价）：

```
/api/v1/plugin/ClipNotes
/api/v2/plugin/ClipNotes
```

鉴权：`apikey` = MoviePilot 的 `API_TOKEN`，可用 query `apikey=xxx` 或请求头 `X-API-KEY: xxx`。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/notes` | 列表 / 增量同步（游标分页） |
| GET | `/notes/{id}` | 单条详情（Markdown、元数据、资源清单） |
| GET | `/assets/{hash}` | 下载图片资源 |
| POST | `/notes/{id}/ack` | 同步确认（写回状态，可校验版本） |
| POST | `/notes` | 提交链接，`{"url": "..."}` |
| GET | `/stats` | 统计与运行参数概况 |

**完整契约（游标语义、字段表、同步循环伪代码、错误码、幂等性）见 [SYNC_PROTOCOL.md](./SYNC_PROTOCOL.md)。**

## 10. 配置项

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 启用插件 | 关 | 插件总开关（命令、菜单、后台服务都依赖它） |
| 命令执行回执 | 开 | 命令执行后是否回复结果 |
| 整理完成通知 | 开 | 笔记处理完成后是否推送结果 |
| 启用微信解析 | 开 | 关闭后微信链接走兜底解析 |
| 启用小红书解析 | 开 | 关闭后小红书链接走兜底解析 |
| 启用抖音解析 | 开 | 关闭后抖音链接走兜底解析 |
| 下载正文图片 | 开 | 关闭则只记录图片地址，不落盘 |
| Markdown 初始状态 | 待读 | 写入 frontmatter 的「状态」 |
| 后台处理间隔（秒） | 30 | 抓取/AI 后台任务的执行周期 |
| 单次处理条数 | 3 | 每轮最多处理几条，避免长时间占用 |
| AI 整理最大重试次数 | 3 | 超过后降级为无 AI 结果 |
| 抓取超时（秒） | 20 | 网页与图片下载超时 |
| 允许的顶层分类 | 10 个内置分类 | 一行一个，AI 只能在其中选择 |
| AI 输入正文上限（字符） | 4000 | 送进模型的正文字符数 |
| LLM 提供商 / 模型 | 空 | 留空使用 MoviePilot 系统配置 |
| LLM 温度 | 0.2 | 建议保持低值，保证分类稳定 |
| 小红书 Cookie | 空 | 可选，遇到反爬时补充 |
| 第三方解析服务 | 空 | 可选，支持 `{url}` 占位，不是硬依赖 |
| 抓取 User-Agent | 空 | 留空使用内置浏览器 UA |
| 微信菜单归属分类 | 订阅 | 企业微信菜单里 ClipNotes 挂在哪个一级菜单下，留空则独立占一级菜单 |

## 11. 任务状态机

```
received ──► parsing ──► ai_pending ──► ready ──► synced
                │                          ▲
                └────────► failed ─────────┘（重试）
```

| 状态 | 含义 |
|---|---|
| `received` | 已收录，等待后台处理 |
| `parsing` | 正在抓取解析 |
| `ai_pending` | 已抓到正文，等待 AI 整理（失败会按重试次数重排队） |
| `ready` | 已生成 Markdown，等待同步端拉取 |
| `synced` | 同步端已 ack |
| `failed` | 抓取失败，可用 `/note retry <id>` 重试 |

## 12. 常见问题排查

| 现象 | 原因与处理 |
|---|---|
| 提示「未识别到有效链接」 | 文本里没有可识别的 URL；可直接发链接（窗口内）或 `/note <链接>` |
| 小红书解析失败 | `xsec_token` 过期或页面结构变化；重新分享一次链接再提交（`content_id` 不变，不会产生重复记录） |
| 微信解析失败 | 页面可能需要验证或已删除；确认链接能在浏览器直接打开 |
| 抖音解析失败 | 抖音对不同 UA 返回不同页面：插件用爬虫 UA 拿 SEO 版本，若被限流会记录失败；稍后用 `/note retry <id>` 重试 |
| 笔记停在 `ai_pending` | LLM 调用失败正在重试；查看 `error` 字段，必要时检查系统 LLM 配置 |
| 笔记 `failed` | 用 `/note retry <id>` 重试，或换一条分享链接 |
| 图片没落盘 | 见 `assets[].error`；通常是 CDN 防盗链或链接过期 |
| 企业微信菜单里没有 ClipNotes | 确认插件已启用；菜单只在命令集变化/插件重载/重启时重注册，重载一次插件即可 |
| 卸载插件后菜单项还在 | MoviePilot 卸载流程不刷新菜单，重启或重载任意插件后消失；想立刻移除请用「禁用插件」 |

## 13. 已知限制

1. **同步是被动拉取**：服务端不推送变更，客户端需按游标轮询；删除墓碑只保留最近 200 条
2. **企业微信菜单**：一级菜单仅 3 个位置，命令较多的分类会被截断，被截断的命令仍可手动输入
3. **小红书**：只做直接 HTTP 解析，遇到强反爬会失败；不使用浏览器渲染
4. **抖音**：只能拿到 SEO 页面里的文案、话题、作者、发布时间、点赞数与封面图；官方接口有签名校验，因此拿不到播放地址与评论
5. **AI 输入截断**：超长文章只取前 N 字符，未实现分段 Map-Reduce
6. **图片**：每篇最多落盘 20 张，视频只记录地址不下载
6. **Markdown 不落地**：正文只存在数据库并通过 API 提供（按设计，Obsidian 侧由独立插件负责写入）
